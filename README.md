# 工廠工令單掃碼記工時（試作）

給工廠現場同仁用手機掃工令單條碼，帶出工令單資料，並記錄開始與結束時間。

> ⚠️ 目前是**測試版**，裡面全部是**編造的假資料**。請勿放入真實工令單號、產品名稱、產品編號或員工資料。

## 現在能做什麼

- **鏡頭對準就自動讀取**工令單號條碼（Code 128），讀到會嗶一聲並震動。
- 也可以**拍照**或**手動輸入**單號。
- 帶出四項：工令單號、產品名稱、產品編號、數量（含單位）。重工單會顯示「重工」標籤。
- 按「開始」「結束」記錄工作時間，列出今天的紀錄。
- 介面語言：中文、Tiếng Việt、Bahasa Indonesia、ไทย。
- 「測試工令單」頁可以顯示 6 張假工令單，用來測試掃描。

## 怎麼試

1. 電腦打開網址，切到「測試工令單」。
2. 手機打開同一個網址，按「掃描工令單」，允許使用相機，對準螢幕上的條碼。

## 已確認的規則

- 工令單號格式：1 個英文字母＋10 位數字（例如 `V1150101001`），開頭字母會變（已見 V、X）。
- 只有存在於工令單資料中的號碼才會被接受。真實單上另有一條客戶訂貨單條碼（H 開頭），會被自動略過。
- 現場畫面只顯示四項；主管畫面之後顯示全部欄位。

## 接上 Google 試算表（約 5 分鐘，由試算表擁有者操作）

App 透過一支放在試算表裡的 **Apps Script** 查單。手機只能「用單號查一張單」，拿到四項欄位，不能列出整份表，也拿不到其他欄位。

1. 打開工令單試算表 → 上方選單 **擴充功能 → Apps Script**。
2. 把編輯器裡原本的內容全部刪掉，貼上本儲存庫的 [`apps-script/Code.gs`](apps-script/Code.gs)，按儲存。
3. 左邊 ⚙️ **專案設定** → 最下面 **指令碼屬性** → **新增指令碼屬性**：屬性填 `PIN`，值填一組工廠密碼（例如 6 位數字）。按儲存。**不要把密碼傳給任何人或寫進程式。**
4. 回到編輯器，上方函式選 `checkSetup` → 按 **執行** → 依畫面授權（用你的 Google 帳號）。下方執行紀錄會顯示「讀到 N 張工令單」。
5. 右上 **部署 → 新增部署作業** → 類型選 **網頁應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   按部署，複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。
6. 把這個網址填進 [`config.js`](config.js) 的 `sheetApi`（或交給維護者填）。網址本身可以公開，沒有密碼查不到資料。
7. 手機打開 App，第一次會要求輸入工廠密碼，之後不用再輸入。

試算表改了之後，最多 5 分鐘會反映到 App。之後修改 `Code.gs`，要用 **部署 → 管理部署作業 → 編輯 → 新版本**，網址才會維持不變。

填了網址之後，網址後面加 `#demo` 仍可用假資料測試。

## 目前的限制

- 紀錄只存在那支手機的瀏覽器，不會上傳。
- 還沒有員工識別與登入；工廠密碼只是暫時的門檻，不是正式權限控管。

## 下一步

## 技術備註

- 純靜態網頁，放在 GitHub Pages。相機需要 HTTPS。
- 條碼函式庫放在 `vendor/`：ZXing（Apache-2.0）、JsBarcode（MIT）。
- 支援 `BarcodeDetector` 的瀏覽器（多數 Android Chrome）用原生偵測，其餘（例如 iPhone）用 ZXing。
